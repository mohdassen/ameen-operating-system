# Ameen Framework Roadmap

**Document owner:** Product / Compliance Content  
**Status:** Working Draft  
**Audience:** Founder, Engineering, Compliance Reviewers, Sales

---

## Purpose

This document defines how Ameen should expand regulatory framework support without damaging trust.

Ameen must never publish a framework simply because it was imported into the database.

A framework becomes customer-facing only when it is sufficiently verified, reviewed, and commercially safe.

---

## Framework Strategy

Ameen is Saudi-first.

The platform should prioritize frameworks that matter to Saudi organizations, especially those connected to cybersecurity, digital government, privacy, cloud, and sector readiness.

---

## Current Framework Position

### Customer-Facing Priority

ECC should remain the first commercially positioned framework because it is the clearest starting point for Saudi cybersecurity readiness.

### Internal Expansion Candidates

Other Saudi frameworks may exist in different readiness states. Ameen must label each framework internally as one of:

1. Acquired
2. Parsed
3. Verified
4. Reviewed
5. Published
6. Commercially Approved

No sales or website page should imply that a framework is fully available unless it is published and commercially approved.

---

## Framework Publication Gate

Before a framework appears as available in customer-facing material, it must pass this gate:

### Source Gate

- Official source captured
- Source URL or origin recorded
- Source date recorded where available
- Source hash recorded
- Source classification recorded

### Content Gate

- Clause counts verified
- Arabic and English alignment checked where applicable
- Importer validation passed
- Corruption and control-character checks passed
- Cross-reference anomalies documented
- Scanned-only content handled through approved process

### Review Gate

- Native Arabic review completed for Arabic clauses
- Saudi GRC practitioner review completed for guidance
- Legal position documented for regulatory text usage
- Product language approved for public claims

### Product Gate

- UI labels accurate
- Framework selection works per organization
- Assessment engine uses the correct framework clauses
- Reports clearly identify framework version
- Customer can distinguish official regulation from Ameen advisory guidance

---

## Priority Order

### Priority 1: ECC Commercial Trust

Before expanding aggressively, ECC must become pilot-ready and trusted.

Required outcomes:

- Legal position documented
- Arabic review complete
- Practitioner guidance review complete
- Output language approved
- Pilot reports consistent

### Priority 2: CCC / Cloud Readiness

Cloud compliance is commercially important because many Saudi entities are migrating workloads and need readiness visibility.

Ameen should support CCC when:

- Source verification is complete
- Arabic content issues are resolved
- Cloud evidence expectations are reviewed
- Website claims are conservative

### Priority 3: DGA / Qiyas Readiness

Digital government readiness can become a strong market opportunity.

DGA/Qiyas support should be positioned carefully as readiness support, not official scoring unless verified and legally cleared.

### Priority 4: Privacy / PDPL Readiness

Privacy readiness can expand Ameen beyond cybersecurity teams into legal, data governance, and compliance teams.

This should be added only when Ameen can clearly separate cybersecurity controls from privacy governance requirements.

### Priority 5: Sector-Specific Frameworks

Future expansion may include sector-specific readiness where there is clear demand, such as financial services, healthcare, energy, and government.

---

## Framework Language Rules

Allowed language:

- "Readiness against"
- "Mapped to"
- "Aligned with"
- "Based on published framework requirements"
- "Helps prepare for assessment"

Avoid language:

- "Certified by"
- "Approved by regulator"
- "Guaranteed compliance"
- "Pass your audit"
- "Official scoring" unless formally verified and legally approved

---

## Framework Expansion Decision Rule

Ameen should not win by claiming the most frameworks.

Ameen should win by being the most trusted Saudi AI compliance readiness platform.

One trusted framework is better than seven weak ones.
