# Ameen Brand Visual Direction

## Purpose

This document defines the first visual direction for Ameen so that the website, product demo, sales deck, and customer-facing material look like one trusted enterprise brand.

Ameen must not look like a generic AI tool. It must look like a Saudi enterprise compliance platform that a CISO, auditor, CIO, procurement team, and consultant can trust.

## Visual Personality

Ameen should feel:

- Trusted
- Calm
- Professional
- Saudi-first
- Modern
- Enterprise-grade
- Explainable
- Controlled

Ameen should not feel:

- Flashy
- Startup-gimmicky
- Crypto-like
- Consumer-app-like
- Overly dark or aggressive
- Too technical for executives

## Core Visual Metaphor

Ameen's main metaphor is:

> From scattered documents to trusted readiness.

The visual system should show transformation:

1. Documents enter the system.
2. AI analyzes and maps them.
3. Controls become understandable.
4. Gaps become visible.
5. Readiness becomes measurable.
6. Humans approve decisions.

## Logo Direction

The logo should communicate trust, assessment, protection, and clarity.

Recommended directions:

### Direction A: Trust Seal

A clean modern mark inspired by a seal, shield, or assurance stamp.

Good for:

- Government trust
- Compliance credibility
- Audit readiness

Risk:

- Could look too much like a cybersecurity company if overused.

### Direction B: Control Map

A geometric mark showing documents turning into connected controls.

Good for:

- AI mapping
- Framework intelligence
- Explainability

Risk:

- Could look abstract if not executed simply.

### Direction C: Arabic Letter-Inspired Mark

A minimal mark inspired by the Arabic concept of "أمين" without making the logo hard to read internationally.

Good for:

- Saudi-first identity
- Arabic-first differentiation

Risk:

- Must avoid looking decorative or traditional in a way that weakens enterprise SaaS positioning.

## Recommended Logo Strategy

Use a hybrid of:

- Trust seal
- Control map
- Subtle Arabic identity

The wordmark should be clean and readable in English and Arabic contexts.

Recommended usage:

- Primary: Ameen
- Arabic support: أمين
- Descriptive line: Saudi AI Compliance Readiness Platform

## Color Direction

The brand should avoid the typical cyber palette of black/red/neon. Ameen is not a threat-detection tool. It is a trust and readiness platform.

Recommended palette direction:

### Primary

Deep green or dark teal.

Meaning:

- Trust
- Saudi relevance
- Stability
- Governance

### Secondary

Warm sand, light pearl, or soft grey.

Meaning:

- Saudi context
- Calm enterprise background
- Premium feel

### Accent

Controlled gold or blue accent.

Meaning:

- Assurance
- Intelligence
- Executive polish

## Color Rules

Use green/teal for trust and platform identity.

Use gold sparingly for highlights, readiness, premium cards, and executive emphasis.

Use red only for risks and gaps.

Use orange/amber for warnings.

Use blue for AI/explainability when needed.

Never make the interface feel like a security operations center.

## Typography Direction

Ameen should use clear, modern, bilingual typography.

English:

- Modern SaaS sans-serif
- Clean spacing
- High readability

Arabic:

- Professional modern Arabic typeface
- Not calligraphic
- Excellent dashboard readability

Typography should support long regulatory text without fatigue.

## Layout Principles

Ameen pages should use:

- Large whitespace
- Clear hierarchy
- Executive summaries first
- Detail available below
- Cards for major concepts
- Tables for comparison
- Visual flows for journeys
- Dashboard mockups for proof

The design must communicate:

> This product reduces complexity.

## Iconography

Use simple line icons for:

- Documents
- AI analysis
- Controls
- Evidence
- Dashboard
- Human approval
- Audit readiness
- Private deployment

Avoid overly technical icons such as circuit boards, hackers, skulls, locks everywhere, or command-line visuals.

## Imagery Direction

Use:

- Abstract document intelligence visuals
- Control mapping diagrams
- Executive dashboards
- Saudi enterprise/government context
- Calm modern office/team imagery if needed

Avoid:

- Random AI robot images
- Stock photos of hackers
- Generic cloud/server images
- Overused padlock graphics

## Product Mockup Style

Mockups should show:

- Upload documents
- AI mapping explanation
- Control readiness dashboard
- Evidence requirements
- Human review status
- Executive report

The product should look simple even when the backend logic is complex.

## Sales Deck Style

The sales deck should be:

- Executive-first
- Minimal text per slide
- Strong diagrams
- Clear problem-solution narrative
- Saudi compliance context
- Trust and risk language

Every slide should answer one question only.

## Website Style

The website should feel like an enterprise SaaS website, not a documentation page.

Hero section should show:

- Strong promise
- Simple workflow
- Trust badges / assurance statements
- Request demo CTA

The above-the-fold message should be understandable in less than ten seconds.

## Product UI Style

The UI should reflect the brand:

- Calm colors
- Clear statuses
- No exaggerated AI claims
- Human approval visible
- Evidence traceability visible
- Official/advisory separation visible

## Visual Trust Signals

Ameen should visually highlight:

- Official-source framework provenance
- Explainable AI
- Human approval
- Local/private deployment option
- Evidence-based readiness
- Audit trail
- Legal boundary statements

## Final Direction

Ameen's visual identity should be:

> Saudi enterprise trust + modern AI clarity + compliance discipline.

This direction should guide all future design work until a professional brand designer produces the final visual identity.
