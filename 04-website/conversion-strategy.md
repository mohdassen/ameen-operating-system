# Ameen Website Conversion Strategy

## Purpose

This document defines how the Ameen website should convert visitors into qualified conversations.

Ameen is not ready for instant self-service selling. The correct first commercial motion is controlled enterprise discovery, demo, and pilot.

## Conversion Philosophy

The website should not try to make every visitor sign up.

It should help serious buyers conclude:

> This is relevant to our compliance problem. We should request a demo or discuss a pilot.

## Primary Conversion Path

Visitor → Understand value → Trust the approach → Request demo → Discovery call → Controlled pilot → Expansion decision.

## Primary CTA

Use:

> Request Demo

Where it appears:

- Hero section
- Navigation bar
- Product page
- AI & Trust page
- Frameworks page
- Solution pages
- Footer

## Secondary CTA

Use:

> Join the Design Partner Pilot

Where it appears:

- Homepage pilot section
- Pilot page
- Government solution page
- Consultants solution page

## Buyer Stages

### Stage 1: Problem Aware

Visitor feels compliance pain but may not know Ameen.

Website must show:

- Manual compliance is slow.
- Evidence is scattered.
- Readiness is hard to measure.
- Ameen creates visibility quickly.

### Stage 2: Solution Aware

Visitor understands AI can help but worries about trust.

Website must show:

- Explainable AI
- Human review
- Evidence traceability
- Local analyzer option
- No exaggerated claims

### Stage 3: Vendor Comparison

Visitor compares Ameen to consultants, GRC tools, and local competitors.

Website must show:

- Document-first workflow
- Saudi-first focus
- Official-source orientation
- Pilot model
- Clear boundaries

### Stage 4: Pilot Decision

Visitor wants to know if a pilot is safe and practical.

Website must show:

- Deployment options
- Scope control
- Expected timeline
- Required documents
- Deliverables
- Success criteria

## Lead Qualification

The demo form should help identify serious buyers without creating friction.

Minimum lead data:

- Name
- Organization
- Work email
- Job title
- Sector
- Primary framework interest
- Message

Pilot qualification data:

- Target framework
- Expected pilot timeline
- Number of documents
- Sensitive/regulated data yes/no
- Preferred deployment model

## Ideal First Leads

Prioritize:

- Government entities
- Universities
- Healthcare organizations
- Large enterprises
- Consulting firms serving Saudi compliance clients
- Managed service providers with compliance offerings

Do not prioritize:

- Very small companies without compliance pressure
- Users seeking free generic AI document analysis
- Customers demanding instant certification
- Customers asking to replace auditors completely

## Trust Before Conversion

Ameen must not use aggressive sales tricks.

Avoid:

- Fake urgency
- Fake customer logos
- Unsupported certifications
- Overpromising automation
- Claiming regulatory approval

Use:

- Clear pilot scope
- Honest framework status
- Human review language
- Data handling statement
- Legal disclaimer
- Product screenshots/mockups

## Website Objections to Answer

The website should answer these objections before a sales call:

1. Does Ameen replace consultants?
2. Does Ameen issue compliance certification?
3. Can documents stay inside our environment?
4. How does AI reach conclusions?
5. Which Saudi frameworks are supported?
6. What happens after upload?
7. How long does a pilot take?
8. What does the customer need to provide?
9. Can consultants use Ameen for clients?
10. What is not assured today?

## Conversion Metrics

Track:

- Demo CTA click rate
- Pilot CTA click rate
- Contact form completion
- Drop-off by page
- Visits to AI & Trust page
- Visits to Pilot page
- Qualified lead percentage
- Pilot conversion percentage

## First Target Numbers

For early pilot website:

- 5-10 qualified demo requests from warm outreach
- 2-3 serious pilot conversations
- 1 paid design partner pilot

The website should support sales; it is not expected to generate all leads organically at the beginning.

## Final Principle

The Ameen website should convert by building trust, not by creating hype.

The visitor should feel:

> This product is serious, honest, Saudi-relevant, and worth a pilot conversation.
