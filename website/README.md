# Ameen Website

This folder contains the first static website prototype for Ameen.

## Purpose

The website introduces Ameen as a Saudi AI Compliance Readiness Platform and converts qualified visitors into demo or pilot conversations.

## Current Scope

This is a static website prototype built from the Ameen Operating System source of truth.

It includes:

- Professional homepage
- Product positioning
- AI and trust messaging
- Saudi framework readiness messaging
- Pilot program call to action
- Safe wording around NCA/ECC
- No claims of regulator approval, certification, legal advice, or guaranteed compliance

## Files

- `index.html` — main website page
- `styles.css` — website visual styling
- `script.js` — small interaction layer

## Safe Claim Rules

The website must not say:

- NCA approved
- NCA certified
- Guaranteed compliance
- Replaces auditors
- Provides legal advice
- Automatically certifies an organization

The website may say:

- AI-assisted compliance readiness
- Evidence-driven assessment
- Human-reviewed recommendations
- Assesses readiness against Saudi compliance frameworks
- Designed for NCA ECC 2:2024 readiness workflows
